public final class InboxStorageLayout
extends EntityGroupLayout<InboxMessageId, InboxMessage, ShardIndex>

    Describes the ancestor-child structure of InboxMessages stored as Datastore entities.

    InboxMessage are grouped by the indexes of shards to which they belong.
